# Форма регистрации разработчика

## Описание
Веб-форма для регистрации разработчиков с сохранением данных в MySQL.

## Технологии
- PHP 7+
- MySQL/MariaDB
- HTML5/CSS3

## Структура БД
- applications - основная таблица с заявками
- programming_languages - справочник языков программирования  
- application_languages - связь заявок и языков

## Установка
1. Импортировать db.sql в MySQL
2. Настроить подключение к БД в index.php
3. Открыть form.php в браузере
